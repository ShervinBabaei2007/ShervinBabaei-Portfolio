Discord
AI Bridge

A Discord bot that bridges messages from a server directly to a locally hosted large language model via LM Studio. Messages are sent to a Qwen model running on a local API endpoint, and the bot replies in real time - no cloud API required.

Python discord.py LM Studio Qwen python-dotenv Local LLM
View on GitHub

What it does

  • Listens for messages in a Discord server
  • Forwards them to a locally running LLM via HTTP
  • Returns the model's response back to the channel
  • Runs fully offline - no external AI API needed

Stack

  • Python 3 with discord.py
  • LM Studio local API (OpenAI-compatible)
  • Qwen language model
  • python-dotenv for config
  • requests for HTTP calls
