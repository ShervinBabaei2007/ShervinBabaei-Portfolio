GitScribe

A developer tool that auto-generates commit message suggestions from git diffs. Available as a CLI published to PyPI and as a web app with GitHub OAuth login. Built at a hackathon and placed top 6 out of 36 teams.

React TypeScript Python Auth0 Vite PyPI Vercel
Live Demo View on GitHub

What it does

  • Analyzes the diff between two file versions
  • Generates meaningful commit message suggestions using AI
  • Supports multiple suggestions at once with the -nm flag
  • Works via CLI or the web interface
  • GitHub OAuth login via Auth0

Stack

  • React + TypeScript frontend
  • Python backend / CLI tool
  • Auth0 for authentication
  • Vite build tooling
  • Deployed on Vercel
  • CLI published to PyPI as gtscr

Two ways to use it

CLI - Terminal

Install once via pip, then run it from any git repo. GitScribe reads your diff and spits out ready-to-use commit messages.

pip install -U gtscr
gs setup
gs generate
gs generate -nm 3

Web App - Browser

Log in with GitHub, upload your old and new file versions, choose how many suggestions you want, and copy the result.

1. Login with GitHub
2. Upload old file version
3. Upload new file version
4. Copy your commit message
