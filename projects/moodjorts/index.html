MoodJorts

A vanilla JavaScript mood board SPA with no frameworks. Cards can be added, deleted, resized, reordered, and persist across sessions via localStorage. Features full undo/redo history, drag-and-drop, keyboard navigation, and a help overlay - all built from scratch without a single dependency.

HTML CSS Vanilla JS localStorage Drag & Drop API SPA
Live Demo View on GitHub

Features

  • Add, delete, and resize mood cards
  • Drag-and-drop reordering
  • Full undo / redo history stack
  • localStorage persistence across sessions
  • Keyboard navigation support
  • Help overlay for new users

Stack

  • Zero dependencies - pure vanilla JS
  • Native Drag and Drop API
  • localStorage for state persistence
  • CSS custom properties for theming
  • SPA architecture, single HTML file

Technical highlights

Undo / Redo

Full history stack implemented from scratch - every mutation is tracked and reversible without any library.

Persistence

Your board saves automatically. Refresh the page and everything is exactly where you left it.

No Framework

Every interaction - drag, resize, reorder, keyboard nav - built with raw DOM APIs. No React, no Vue, no jQuery.
