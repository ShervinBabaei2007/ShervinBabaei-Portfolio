Project - MERN Stack

ThinkBoard

A full-stack notes application built on the MERN stack. React frontend, Express REST API, and MongoDB for persistence - with full CRUD operations, clean component architecture, and a frontend/backend monorepo structure.

MongoDB Express React Node.js REST API MERN
Live Demo View on GitHub

Features

  • Create, read, update, and delete notes
  • React frontend with component-based architecture
  • RESTful API with Express routing
  • MongoDB for flexible document storage
  • Frontend and backend in a single monorepo

Stack

  • MongoDB - document database
  • Express - REST API and routing
  • React - component-based UI
  • Node.js - server runtime
  • Monorepo with frontend/ and backend/ split

MERN Architecture

Frontend

React

Component-based UI, state management, and API calls to the Express backend.

API Layer

Express

REST endpoints handling CRUD operations, routing requests to the database layer.

Runtime

Node.js

Runs the Express server, handles middleware, and manages the application lifecycle.

Database

MongoDB

NoSQL document store for flexible note storage without a rigid schema.
